📌 About the Project

Ping-Pong Game is a game development project inspired by the classic table tennis game. It aims to provide a more modern gaming experience while maintaining the basic concept of the original game.

This project was created as part of a school assignment.

The game concept and ideas are my own, with assistance from Claude AI during the coding process.
